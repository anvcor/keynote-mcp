# 美科AF 50mm F1.4 MIX：专利逆向与无穷远、0.02倍性能（分节稿）

> 档位：送测档（厂商送测、下周解禁、评论区抽奖）。本稿只写「专利逆向与光学设计」和「无穷远 + 0.02倍」两部分，开场的送测声明与抽奖信息、官方MTF入口帧留给其他章节。

## 一 专利逆向与光学设计

[图1：专利首页截图，标出公示日 2025年11月、申请日 2024年8月；旁边放一条时间轴，末端是本次解禁日期]
在85MIX2那期结尾我们还在催更美科的50mm F1.4。其实这枚镜头的设计，早在2024年8月就已经提交了专利申请，专利号CN【待填：完整专利号】。2025年11月公示。也就是说，从申请到这次解禁，这个设计在美科手里差不多放了两年。

[图2：实施例1结构图与用户说明书量产结构图左右并排，标出对不上的位置]
专利一般会给出好几个实施例。先看实施例1，如果你把它和说明书里的量产结构图放在一起对比，很快就能发现它们对不上。【待填：具体哪里不一致，例如片数/某片正负/非球面位置】。所以实施例1并不是量产的透镜设计，需要继续往后翻。

[图3：实施例3结构图与说明书量产结构图并排，逐片连线对应]
翻到实施例3。很明显，这就是符合实物量产的设计。镜片数量、各片的正负以及非球面的位置，都能和说明书的结构图一一对上。

[图4：还原后的Layout叠加在说明书官方结构图上]
将优化还原后的Layout叠加在官方结构图上，【待填：拟合程度描述，例如"仅在非球面和个别表面有微小的曲率半径差"/相似度】。当然，还是要老实交代，逆向还原的结果只能做性能参考，像差趋向并不保证和设计原档完全一样。

[图5：还原结构图，G1/G2/G3分色标注，非球面与ED镜片用不同记号标出]
这，就是美科AF 50mm F1.4 MIX的光学结构。一共13片【待填：X组】，其中2枚为双面压铸非球面镜片，分别是第1片负镜和最后一片；另外还有3枚ED镜片。整体按功能分为三个透镜群，G1、G2、G3。

[图6：G2对焦群从无穷远到最近对焦的位移动画，箭头指向物方，标注"内对焦 / VCM"]
对焦依靠G2群完成。G2是两片镜子组成的正光焦度透镜群，近摄时向物方位移合焦。对焦过程中镜头总长不变，也就是内对焦。马达是VCM音圈马达。不过参与对焦的只有两片镜子，近摄时像差的平衡主要靠这两片撑着，这一点我们在后面0.02倍的仿真里会看到。

[图7：光学总长 98mm、BFL 16mm 标注在Layout上，旁边并列我们以往逆向的唯卓仕55EVO（约90mm）、福伦达50APO（约73mm）]
美科50 F1.4 MIX的光学总长大约98mm，后焦BFL为16mm。相比我们之前逆向过的唯卓仕55EVO的约90mm，还要再长一截；比福伦达50APO的约73mm更是长出了一大截。当然，对于光学设计来说，总长更充裕就意味着更多的设计budget，关键还是看它能不能把这些长度换成性能。

[图8：G1高亮，标出第1片双面压铸非球面，以及H-ZF73、NBFD25所在镜片位置]
先来看G1群。第1片负镜就是一枚双面压铸非球面。放在最前端，这里轴外光束和轴上光束分得比较开，非球面主要用来平衡轴外像差，【待确认：结合还原数据看它主要在平衡畸变/像散还是彗差】。材料上，按专利的折射率和阿贝数反查，G1里用到了成都光明的H-ZF73和HOYA的NBFD25。H-ZF73属于超高折射、高色散、高部分色散的材料；NBFD则是HOYA的铌短火石系列，目前还很难找到国产替代。【待填：3枚ED分别位于哪一群】。

[图9：G2高亮，标出FDS18正镜]
对焦群的材料选择也很关键。G2的正镜用的是HOYA FDS18，同样是超高折射、高色散、高部分色散一类的玻璃。用在对焦群里，一方面高折射率可以用更平缓的曲率承担正光焦度，另一方面它的部分色散可以和其他材料配合修正色差，减轻对焦位移时色差的变化。【待确认：还原数据中G2另一片的材料】。

[图10：G3高亮，标出最后一片双面压铸非球面，以及它和像面、BFL的相对位置]
G3后组的最后一片，是第二枚双面压铸非球面。它离像面最近，轴外各视场的光束在这里基本已经分开，所以更多是在修正场曲、像散，同时控制边缘的主光线角度。高精度双面压铸非球面是好东西，但它精贵，美科在前后两端各放一枚，可以说是把钱花在了刀刃上。【待填：G3其余镜片材料，如有需要】

[图11：Datasheet表格——面序号、曲率半径、厚度、玻璃牌号、非球面系数]
最后，我们整理了此次优化还原后的设计数据。如果你想以该镜头作为光学设计初始结构，可以根据数据做仿真。有需要可以暂停视频对照表格。

## 二 性能仿真与测量

[图12：无穷远全视场FFT MTF，标出中心MTF50约190线对每毫米]
来到光学设计软件的仿真全视场FFT MTF。无穷远下，美科50 F1.4 MIX的中心MTF50大约在190线对每毫米左右。这和我们逆向的索尼100GM无穷远约180线对是同一档的表现，放到F1.4的标头里算是相当强劲了。当然，比起自家85MIX2约250线对的仿真值还是低一档，不过两者的视场角和设计难度并不相同。

[图13：同一张FFT MTF，放大16mm像高之后的区域，标出最边缘40线对反差0.55]
再看边缘。大约在16mm像高之后，也就是七成多视场的位置，子午曲线开始往下掉，而弧矢还比较稳。只有子午先掉，通常是子午场曲或者子午彗差在作怪，【待确认：看Rayfan确定是哪一项主导】。不过到了最边缘，40线对的反差依旧有0.55，并没有出现坠机。

[图14：无穷远纵向像差，色焦移曲线放大到±40微米，标出0.7光瞳处三色交点与光瞳末端宽度]
来到色焦移这一块。光瞳末端的色焦移宽度为31微米，比85MIX2顶端的24微米要多一些，也刚好越过了30微米这条顶级水平线。但在0.7光瞳附近可以找到三色光重合，腰部宽度只有9微米。曲线形态上，这是符合复消色差的设计。

[图15：同一张纵向像差，用横线标出F2对应的光瞳高度（约0.7）]
当然，光瞳末端这31微米也很好解决。F1.4收到F2，光瞳高度差不多就缩到原来的0.7，正好切到三色重合的那一段，末端的色焦移就被裁掉了。至于球差，【待填：无穷远球差形态——欠/过矫正、有无拐点、收光圈后的变化】。

[图16：物距2.6米（0.02倍）全视场FFT MTF，与无穷远曲线叠加对比，标出14mm开裂点]
继续近摄到2.6米，此时的放大倍率大约来到0.02倍，差不多是50mm拍全身人像的距离。中心MTF50从190掉到了165线对每毫米左右。更明显的是轴外，子午弧矢在14mm像高就开始开裂，比无穷远时的16mm提前了一截。原因不难猜测：对焦只移动G2那两片镜子，无穷远下平衡好的轴外像差，在物距变化后就平衡不住了。两片对焦，也别指望奇迹。

[图17：MTF Mapper打靶结果，a7r4a，中心MTF50 88线对每毫米；旁边标注3.76微米像素的测量上限]
当然，我们也用a7r4a打靶测量了分辨率【待确认：打靶物距】。中心测到了88线对每毫米。这个数字其实已经顶到了a7r4a的测量天花板，3.76微米的像素最多也就测到90多线对。而仿真的中心MTF50在165到190线对之间，想要测出这个量级，需要小于2微米的像素。所以a7r4a现在测不出这枚镜头的完整表现，实测只能看趋势。【待填：边缘/中场实测数据，如需与仿真拟合】
