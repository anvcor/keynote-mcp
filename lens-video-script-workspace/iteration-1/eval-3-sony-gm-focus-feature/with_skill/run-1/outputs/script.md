## 开场（正文）

[图1：四枚镜头的量产结构图按时间纵向排列：85GM → 50GM → 85GM2 → 100GM。对焦群统一用一种高亮色，其余镜片置灰。]
如果你把索尼这几年的GM定焦结构图按时间排在一起，只盯着对焦群的颜色看，会发现一件很有意思的事情：对焦群越来越"碎"了。一代85GM还是【待确认：85GM对焦群片数】片镜子组成的一整组，前后推到底；到了50GM和85GM2，对焦被拆成了两组，各走各的行程；再到100GM，【待确认：100GM逆向结果中对焦群的分组数与片数】。与此同时，驱动它们的马达也从【待确认：85GM马达类型，是否为环形SSM】，换成了一颗又一颗XD线性马达，也就是VCM音圈马达。

[图2：100GM那一期的封面截图 + 一张"二维到二维 vs 三维物体"的示意图（无穷远平面物 vs 0.02–0.1倍的人像/拍菜工况）]
我们在100GM那一期就反复强调过，近摄才是最考验光学设计的工况。无穷远只是二维到二维的成像，而拍全身、拍大头、拍菜，都落在0.02到0.1倍这个区间，拍的是三维物体。在这个区间里，镜头的像差会随着物距改变而重新分配：球差在变，场曲在变，彗差也在变。能不能把它们重新压回去，基本就看对焦组怎么设计。说白了，一枚镜头的近摄天花板，在决定对焦组的那一刻就已经写好了。

[图3：各代GM官网/发布会宣传页拼图，高亮与对焦相关的宣传语（速度、追焦、静音、呼吸抑制）]
当然，厂商的口径不太一样。在索尼的营销里，多组浮动对焦和多颗XD线性马达，几乎都是和"对焦速度""追焦""视频静音"绑在一起讲的。这没有错，但只说了一半。本期想回答的问题是：索尼越来越爱用多浮动对焦组和VCM马达，到底是为了快，还是为了近摄像质？又或者，这两件事其实是同一个问题的两面——是先有了轻巧的VCM，逼着对焦组越拆越小；还是先有了多浮动的光学需求，才不得不上线性马达？

[图4：时间轴帧。85GM【待填：发布年份】→ 50GM【待填：发布年份】→ 85GM2【待填：发布年份】→ 100GM【待填：发布年份】，每个节点下放对焦群示意和马达配置]
所以本期是一个专题，不给单品打分。我们沿着时间线往下走：从【待填：发布年份】的一代85GM，那个还是单组对焦的时代；到50GM，【待确认：50GM是否为本期讨论范围内第一枚"多组浮动 + 多颗XD马达"的GM定焦】；再到85GM2，同一个焦段、同一个F1.4，对焦组被推倒重来；最后是100GM，一枚要从无穷远一路对到1倍的微距镜头，对焦组要吃下的像差变化量，是前面几枚完全不能比的。

[图5：数据来源说明帧。表格：镜头 × 数据来源（专利仿真 / 逆向优化 / 待定）× 专利公开号 × 备注（逆向相似度、与量产结构图的偏差）]
先交代一下数据来源。85GM和85GM2都能找到对应的专利，我们按专利实施例在Zemax里做了仿真【待填：两份专利的公开号、公示日、申请日】；100GM则是我逆向优化的版本，像差趋向并不一定和设计原档一样，只能作为性能参考。50GM的数据来源【待填：专利仿真 / 逆向 / 暂无】。另外，众所周知我对85焦段兴趣不大，这一期却一口气放了两枚85。没办法，同焦段、同光圈的一代和二代，是观察对焦组进化最干净的对照组，其他变量都被控制住了。

[图6：目录帧："一 为什么物距一变，像差就变""二 一代85GM""三 50GM""四 85GM2""五 100GM""六 马达与对焦组：谁先谁后""结尾"]
视频将分为七个部分。我们先用一个最简单的模型讲清楚，为什么物距一变像差就会变，以及浮动对焦到底多给了设计师什么。然后四枚镜头按发布顺序逐个过，每一枚都看对焦群怎么分、怎么走、多重，以及在0.02倍、0.06倍和最近对焦时付出了什么代价。最后我们再回到马达，讨论一下这到底是鸡生蛋还是蛋生鸡。如果你只关心结论，可以直接跳到最后一部分。当然，可以先偷偷告诉大家，本期会有一些暴论。
