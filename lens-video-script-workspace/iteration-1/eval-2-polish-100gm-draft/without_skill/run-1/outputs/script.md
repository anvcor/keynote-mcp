# 0.5 倍放大倍率：100GM vs 适马 105DN

然后我们来看 0.5 倍的时候，100GM 和适马 105DN 的对比。

先看中心。这个倍率下，100GM 中心的 MTF50 大概在 90 线对，105DN 则有 105 线对左右，这一项 100GM 是被肘了。毕竟 105DN 的对焦组里参与成像的镜片更多，近距离下的校正余量也就更足一些。

再看边缘。到了边缘两颗其实都有劣化，但 100GM 的子午坠机比较厉害，大概过了 15mm 像高之后就不太行了。

然后看离焦点列图。100GM 的背景光斑带亮边，这是球差过矫正的表现，相对的，前景会比较柔和。105DN 这边会稍差一点，但球差整体比较中性。

最后是实拍，我拍了一个手表表盘。放大来看，100GM 在表盘刻度边缘能看到一点紫边，而 105DN 几乎看不到。

所以我的结论是：纯微距工况下，105DN 还是更强；但 100GM 的对焦速度快太多了，日常用的话，我还是会选 100GM。
