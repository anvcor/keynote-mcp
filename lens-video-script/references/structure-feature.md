# 专题史文稿骨架（以《3D Hifi》为范本）

用于厂商设计理念、镜头设计史、设计师人物线、某种像差设计思路的演变。与评测稿的区别：

- 段落更长（常 150–400 字），一段可以覆盖几帧；仍然给出 `[图N：画面建议]`，但可以一段配多张图。
- 以**人物和年代**为主线，大量引用访谈、专利、官方文章（如"尼克尔千夜一夜"、dc.watch 访谈）。**引用的原话和出处都必须来自用户提供的资料**；需要引用却没有资料时写【待填：出处/原话】。
- 文末附「参考文献」列表（编号 + 标题 + 链接），由用户提供的资料生成。
- 语气更正式、叙事感更强，但仍保留他的梗（"我超冰""一颗赛艇""原田不语，只是一味Hifi"），密度约每 4–6 段一处。

## 骨架

1. **开篇**：公司/主题的宏观介绍 → 今天要讨论的理念 → 时间线预告（"从佐藤治夫的单反终曲时代，再到新生无反Z卡口的原田壮基"）→ "视频将分为X部分"。
2. **按时代分部分**（不一定用「一 二 三」标题，可用时代转场句）：
   - 转场句："时间拨回到1987年。""在2013年尼康发布完58G和Df后。""2018年，……属于尼康的无反相机时代终于开启。"
   - 每个时代：人物介绍（入职年份、专利数、代表作）→ 代表镜头/专利 → 用仿真解读设计（球差、MTF、离焦点列图、Rayfan）→ 实拍样张对照 → 小结这一代人对理念的贡献。
3. **概念讲解插段**：在需要的地方停下来讲清楚一个概念（欠/过矫正球差与前后景光斑、二维到二维的评价体系为什么不够、BFL 与法兰距、CRA）。用"我们"带读者一步步推：先模型、再光线追迹、再结论。
4. **轶事插段**：发布会、庆祝活动、访谈现场，增加叙事温度。
5. **结尾**：一段回顾整条时间线（"在穿越到1970年……再到……"）→ 对未来的推测（"本台认为还需要至少7到10年"）→ 开放式收尾。
6. **参考文献**。

## 评价镜头时仍沿用评测的工具链

无穷远与近摄（0.02 / 0.06 / MFD）的 FFT MTF、离焦 MTF、球差曲线、Rayfan、离焦点列图，并与实拍光斑对照。区别只是目的：专题里这些数据用来证明"设计理念是否落地"，而不是给单品打分。
