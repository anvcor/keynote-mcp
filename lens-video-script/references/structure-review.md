# 评测类文稿骨架

适用于单镜头评测、同日发布的双子镜头、同一产品矩阵的两三枚镜头（每枚一章）。章节可以根据素材增删（外观章节可省略；没有实测就跳过打靶帧），但**顺序和每个物距的小循环**基本不变。

帧数参考：单镜头 40–60 帧；双镜头 70–80 帧。

---

## 开场（3–6 帧，不设章节标题）

按需选用：
1. **回顾 / 背景**：上一期做过什么、这个品牌或焦段的历史、自己当年的购买经历（自由档常用"我"的故事）。
   > 在快一年前，我们就体验过美科AF 24MIX。这枚镜头给我们的印象就是非常强悍的消色差表现。
2. **产品定位 / 市场**：发布了什么、同类竞品格局、厂商营销在强调什么（"APO""萤石"这类"性能安全词"）。
3. **本期问题**：一句话抛出核心疑问——"是否真APO？""微距镜头不拍微距？"
4. **流程预告**："依旧是全流程，包括光学设计仿真、测量、实拍的呈现。"可以剧透一点结论吊胃口："当然，可以先偷偷告诉大家……"
5. 送测档：送测声明（"由于测评的《规范》要求……当然，国产摄影器材厂商对于KOL是宽松的。我们还是能有独立人格的。"）+ 福利/抽奖信息。
6. 自由档可选：暴论预告（"本期将是爆论Time"），说明为什么不做横评、为什么拖更。

## 一 专利逆向与光学设计（8–15 帧/枚）

1. **专利来源**：公示日、申请日，与发布日的先后。
2. **找实施例**：专利首页结构图 vs 用户手册量产结构图；不一致就去找其他实施例。可以吐槽专利的"坑"（非球面系数是假数据、材料是初始设计的、结构图对不上）。
3. **还原结果叠图**：还原 Layout 叠加官方结构图，说拟合程度，老实交代偏差（"仅仅在非球面和一些表面有微小的曲率半径差""90%相似度"），可提花了多久。
4. **「这，就是……的光学结构」**：片数、组数、非球面/ED 数量、按功能分群 G1/G2/G3（或 G1–G5），对焦群是哪几片。
5. **对焦方式**：对焦群光焦度正负、向物方/像方位移、内对焦还是外对焦（总长变不变）、单片/双浮动/三群全动，由此预告近摄表现。马达（STM/VCM）与对焦组重量可顺带。
6. **光学总长**：数值 + 与竞品/前代/"人手掌"比；BFL、滤镜口径、增距镜兼容等尺寸约束。
7. **逐群讲材料与非球面**（每群一帧）：玻璃牌号（CDGM/HOYA/OHARA/HIKARI 对应物）、非球面位置和作用（平衡哪种像差）、为什么放这里、成本限制下的取舍（"只可惜由于成本限制……不然可以进一步矫正彗差"）。
8. 可选深挖：nd-vd / PgF-vd 玻璃图、镜片加工能力（边缘厚度）、机械/镜片质量比、压铸非球面工艺。
9. **Datasheet 帧**："最后，我们整理了此次优化还原后的设计数据。如果你想以该镜头作为光学设计初始结构可以根据数据做仿真。"

## （可选）镜头外观（3–6 帧）

前玉铭文（拥挤/克制、印刷/刻槽）、光圈环（有无 Click 切换、锁定）、按钮（AF/MF 开关是不是"祖传通用零件"）、尾玉与卡口螺丝、外壳材质。以吐槽为主、夸得克制。送测档放在专利章节之前也可以。

## 二 性能仿真与测量（15–25 帧/枚）

**入口**：官方 MTF。判断掺水程度——30 线对反差超过衍射极限说明用的是几何 MTF。"快速看镜头性能其实很简单，看看30线对有没有超过0.85反差即可。当然首先得判断厂商的MTF掺水的多少。"

**然后按物距推进，每个物距一个小循环：**

| 物距 | 典型放大倍率 | 对应工况 |
|---|---|---|
| 无穷远 | 0 | 风景、远摄 |
| 全身人像距离 | ≈0.02 | 85mm 约 4 米；50mm 约 2.6 米；35mm 约 1.7 米 |
| 半身 / 大头 | ≈0.06 | 85mm 约 1.5–1.6 米；50mm 约 0.9–1 米 |
| MFD | 最大倍率 | 最近对焦 |

小循环内的帧（按需取舍）：
1. **全视场 FFT MTF**：中心 MTF50、哪个像高开始下降、最边缘的线对反差、子午弧矢是否开裂；与竞品/前代同工况对比。线对常用 10-20-40-80，高性能镜头加 160 甚至 320。
2. **纵向像差（球差 + 色焦移）**：绘图宽度（±40 微米 / ±0.2 毫米）、光瞳末端色焦移宽度、球差欠/过矫正、有无拐点、收光圈能否切掉。**APO 判定**：找到三色光重合的光瞳高度（色焦移曲线三个焦点）。
3. **实测**（有数据时）：MTF Mapper + 相机（a7r4a 3.76 微米）或 ImageMaster 无穷远；说明像素尺寸造成的测量上限，趋势和仿真是否吻合，公差迹象。
4. **离焦点列图**：背景/前景光斑的亮边、带核、彗差、菱形、渐晕压缩、色边颜色（背景黄/前景蓝紫之类）。
5. 可选：相对照度（边缘照度、EV）、CRA、离焦 MTF、Rayfan。

性能章节的语气主线是"随物距推进，性能如何劣化、劣化来自哪个像差、根源是哪个设计决策（通常是对焦组）"。

## 三 实拍（8–15 帧/枚）

顺序大致：远摄样张 → 100% 放大中心/边缘 → 近摄（拍菜、拍人、拍猫）→ **地狱工况找色差**（大逆光高光过渡区）→ 离轴虚化光斑。

每帧写：拍摄条件（机身、光圈、物距）→ 看哪里 → 看到什么 → **对回仿真**（"就是这样水灵灵的在实拍图中出现了"）。提醒物距的重要性："你不能拿最近对焦爆了的色差指责它，因为完全不是同个工况。"

可选：非成像表现（FOV 内/临界/外杂散光、鬼影），对比同场其他镜头。

## 总结 / 结尾（3–6 帧）

1. "综上，……"：完成度评价，一两个最突出的优点，一两个 Trade-off（常是非球面数量、对焦组设计、成本）。
2. 价格与定位（"只比……贵了400块钱。当然也可以理解为是那块双面压铸非球面的成本。"）。
3. 对厂商的期望 / 催更（"我们还是要催更美科，把50mm F1.4和35mm F1.4发布的。"）。
4. 行业感慨（国产向下螺旋、当年同价位只能买什么）。
5. 可选彩蛋：专利里的未发布新品前瞻。
6. 自由档可以用一句狠话或横批收尾；送测档附福利/购买信息与"别忘了关注"。

## 多镜头组织

- 双子镜头：「一 55EVO」「二 35EVO」各自走完整流程，第二枚可以简略（"和55EVO一样……对焦群依旧是G2那两片"），然后「结尾」合并总结。
- 产品矩阵中的两三枚：可以在每章开头先"推测设计指标"（前代产品的性能、尺寸、马达约束），再看新镜头如何满足。
- 与竞品对照：每个物距小循环里放一帧竞品同工况的 MTF 或点列图即可，不必另起章节。
