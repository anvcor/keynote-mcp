# 《35之月》协作经验（2026-11-03 → 11-05，Windows + PowerPoint）

这一期（唯卓仕 AF 35mm F1.4 Pro / 中一 AF 35mm F1.4，对照索尼 35GM、适马 35 DG II）第一次整期在 Windows 上用 PowerPoint 做草稿，几个 Claude 会话分工完成，最后交到 Mac 上用 Keynote 重做。下面记下这期摸出来的做法和坑，下一期直接照着用。

## 1. 分工和交接

| 会话 | 负责 | 不碰 |
|---|---|---|
| 写作（主会话） | `文稿.md`（每段前 `[图N]`）、`课题卡.md`（进度、图号 → 页号、待定事项）、飞书同步 | 原则上不改 PPT |
| 制图 | `35之月动画.pptx` 和所有图片：结构图、MTF、光斑、专利页、截图、封面 | 不改文稿 |
| 制图 (fork) | 实际写了后记、图52、图53 的段落，算了后记的对焦全程曲线 | |
| 网页开发 | lens-bench（截图里的网页） | |

- **交接的介质就是文件**：课题卡记「图N → 第几页」、待确认的事；PPT 备注第一行是 `[图N]`；会话之间用 `list_events` 读对方最近的记录，不靠记忆。
- **临时图号**：后记先用「后记图1–5」，写作会话统一重编成图47–51 后，制图会话照文稿改备注。改号前先读一遍文稿，不要凭印象。
- **两个会话都会改 PPT，作者也在实时改**（删页、插页、改大小）。这一期出过：作者刚删了一页，制图会话按旧页号在一页非空白页上建了三页结构图，只好删掉重做。写作会话也改过第 102 页截图大小、补过备注。所以有下一节的规矩。

## 2. 改 PPT 的规矩

1. **每次动手前重新读文稿**（`get_deck`），脚本里先 `assert` 目标页和左右相邻页的对象数，对不上就停，不要按记忆里的页号写。
2. **改完自己导出看**（`Slide.Export` 或 `view_slide`），确认了再回话。
3. **回话只写文字和页号**：作者自己开 PPTX 看，不要往对话里发图（2026-11-05 起）。
4. 工具新建的对象名一律 `!!` 开头，神奇移动靠同名配对；同一组神奇移动页里，同一个东西名字要一样。
5. 内容页之间夹空白页；放大、续页这类连续页直接相连，切入用 0.8 秒平滑。
6. 字幕区 y > 1000 不放内容。作者要求放大、铺满时可以破例，但要告诉他哪一块进了字幕区。

## 3. 作者怎么给反馈

- 句子很短：「你这是180°」「底部没对齐」「放大一下」「没居中」「框和其他两个有点小差别」。几个像素、1–2% 的尺寸差他都看得出来：并排的图要**做到完全一样的尺寸和基线**，不是「差不多」。
- 「顺时针 / 逆时针 90°」容易理解反。PowerPoint 的 `Rotation` 是顺时针；拿不准就按他给的截图对一下方向再动。
- 「参考 XX」「你看官方的说明书」：去看他说的那个东西（以前的封面、说明书 PDF、某一页），不要自己发挥，也不要先去网上找替代品。
- 截图、图表他偏好大：先按字幕区规则排，他说放大就放大。

## 4. 这期新加的页面做法

- **很长的镜头**（唯卓仕 35 Pro 全长 127 mm）：14.3 px/mm 放不下 12 mm 入射光线，比例改成 `1832 / (全长 + 12)`，`layout_pages.py --ppm` 用同一个比例。见 [结构图规范.md](../结构图规范.md) 末节。
- **三只同门镜头结构对比**（唯卓仕 35 / 50 / 85 Pro）：同一比例、像面右对齐、线宽 ×0.6 的细线版 SVG；对焦组用白色 72% 透明的同形状色块提亮（独立对象）。对焦组从仿真文件里哪几个间隔随对焦变化来判断；只有光阑间隔在变时判断不了，要写明是假设（85 Pro 就是）。
- **zmx → CODE V**：用 cv2zmx 网站的 JS（`zmx2seq.js`）在本地 node 跑，再 `in a.seq` + `SAV`。非无穷远组态的 MTF 图题要自己设：`mtf_vs_field_page.py --pre 'TIT "1.7M"'`，不然图上写的还是 INF。
- **官方 MTF 横排**：从说明书 PDF 的矢量页按区域渲染（PyMuPDF，14 倍），三张拆成「图框」「图例表」两段，统一成同样的高度和间距再拼回去，底边才能对齐。
- **一张曲线图分段讲**（后记）：不要把同一张图裁切放大（会丢坐标刻度），而是按每段的坐标范围重画（`对焦曲线/plot_zoom.py`）；图例做成页面上的原生线 + 文字，几页位置不变，神奇移动时不跳；标注圈的像素坐标由画图脚本输出（JSON），页面上的中文标注按它摆。
- **网页截图**：内置浏览器和 Chrome 扩展的截图只回给模型，存不成文件；selenium 缺 chromedriver。用 `tools/web_screenshot.py`（无头 Chrome + DevTools 协议），可以先跑一段 JS 选好镜头，`--scale 2` 出 3840 宽给 4K 导出。页面背景改成截图边缘的颜色（lens-bench `#0E1114`，GitHub `#0D1117`），图和页连成一片。
- **封面**：1920×1080，主要内容放在中间 4:3 安全区（x 240–1680），另存一张 4:3 裁切。风格照 lens-bench 那期：深灰底、两行大字、关键字标红（#FF644E）、下面放产品图或软件截图。

## 5. PowerPoint COM 的坑

- `AddPicture(..., Width, -1)` 有时按 1080 高拉伸，读原图宽高比自己算两个值。
- 文本框 `WordWrap=0` 加 `AutoSize=0` 后宽度会塌成几 pt（字照样显示，但到 Keynote 可能折行）：设完文字再把 `Width` 设回去。
- 新文本框会带上模板的段前段后距，多行标注行距变得很大：`SpaceBefore = SpaceAfter = 0`、`SpaceWithin = 1`。
- 文本框垂直居中用 `VerticalAnchor = 3`，再按线的 y 减半个框高放。
- 插空白页：复制一张现有空白页 `Slides(k).Duplicate()`，再 `MoveTo` 到位置，转场设置一起带过去。
- 单页背景：`FollowMasterBackground = 0`，`Background.Fill.Solid()`，再设颜色（COM 的 RGB 是 BGR 顺序）。
- `tools/datasheet_page.py` 要 85MIX2 的模板文稿开着（只读打开），不然 `StopIteration`。
- 在 Bash 工具里用 heredoc 写 Python，代码里的 `'\\'` 会被吃成 `'\'`：带反斜杠的脚本用 Write / Edit 写文件。

## 6. 交到 Mac

- Keynote 导入 pptx 不保留 SVG 图片：`tools/extract_svgs.py deck.pptx 输出夹` 把每页的 SVG 连同位置（pt）导出来，Mac 上渲染成 2× PNG 放回原位。
- 产品图在 pptx 里带 `KMCP_FILE` 标签，记着原图路径；PowerPoint 压缩过的图都要换回原图。
- 交接说明写在项目文件夹的 `交接_Mac_Keynote.md`：页面清单（页 → 图号 → 素材 → 注意）、SVG 和原图怎么换、哪些页背景特殊、哪些文字位置要按 Helvetica Neue 复核、构件动画先问作者、待确认事项。下一期照这个结构写。
