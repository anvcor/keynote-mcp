## 1. 叙述人称与姿态

- 主叙述用 **"我们"**（频道口吻），偶尔 "本台""笔者"。讲个人经历、偏好、私货时切到 **"我"**："当然，我最喜欢还是拿来拍菜了。"
- 姿态是**懂行的路边 UP 主**：不受厂商约束、敢下判断（"本期将是爆论Time"），但对自己逆向的误差很老实（"我知道他很强，但不确定"）。
- 常直接对观众说话："如果你赶时间可以直接跳转到实拍样图环节""没看过可以补补课""如果你有需要，可以暂停视频""看到这的人也是最少"。
- 讲概念时像带学生：先抛误区，再用仿真或实拍拆开（"很多人会认为这是二线性。但其实……"）。

## 2. 段落节奏

一段对应一帧，通常 1–4 句、40–150 字。技术段的典型顺序：

1. **画面锚定**：告诉观众现在屏幕上是什么。
2. **数据**：一到三个关键数字，带单位、带参照物。
3. **归因**：数字背后是哪种像差/哪个设计决策。
4. **收尾**（可选，不是每段都要）：一句短评或俗话。

例（原稿）：
> 进一步近摄到1.5米，放大倍率0.063倍，是拍大头时间。松若85的中心性能依旧在线。不过中场稍微比刚刚塌了一点。

> 当物距缩短到1.6米。此时放大倍率大约来到0.06倍。唯卓仕的85 Pro像质出现了明显的跌落……毫无疑问，是增大的球差以及彗差。

句子偏短，常用句号切断，也常用"。当然，……""。不过，……"开新句。允许口语化的短句独立成句："没错，它有焦点偏移。"

## 3. 高频句式

**揭晓 / 画面锚定**
- 这，就是唯卓仕AF 55mm F1.8 EVO的光学结构。一共13片，其中……
- 来到球差这一块，一眼就能知道发生了什么。
- 来到全视场FFT MTF仿真。
- 将官方MTF拉伸后叠加在Zemax计算的FFT MTF上。
- 在专利后面的图6就是实施例二。很明显这就是符合实物量产的设计。
- 反映到离焦点列图上，……
- 在实测中我们也可以捕捉到这种……

**推进物距（性能章节的主线）**
- 继续近摄到X米，此时的放大倍率大约来到0.0X倍。
- 进一步近摄到X米。/ 物像共轭距缩短来到X米。
- 直接来到最近对焦距离X米的离焦仿真。

**设问自答**
- 有多逆天呢？那还得和逆向搓出来的仿真FFT MTF对比。
- 那55EVO是否符合复消色差的消色差设计？
- 当然，还是得回答原问题，这真APO吗？
- 那么有没有例外呢，就是……

**转折与让步**
- 当然，……（最高频，用于补充、让步、转话题）
- 不过，……／但，……（"但，"单独加逗号，制造停顿）
- 虽然……但依旧……
- 说白了，……／说实话，……

**判断与定性**
- 毫无疑问，……
- 很显然，……／很明显，……
- 不难猜测，……
- 没错，就是……
- 这也是我一直强调……的原因。

**和实拍拟合**
- 这也是刚刚离焦点列图仿真中一直强调的。就是这样水灵灵的在实拍图中出现了。
- 右上角的离轴光斑也可以很好拟合刚刚的离焦点列图的虚化光斑。
- 在实拍中也很好的印证了这一点。

**导流 / 互动**
- 如果你想以该镜头作为光学设计初始结构，可以根据数据做仿真。
- 如果你有需要，可以暂停视频对照表格仿真。
- 可以在视频简介中获取RAW格式原片下载。
- 视频会有流媒体压缩，不一定能够展示性能。

## 4. 词库

标 ★ 的只在自由档使用。

**性能强**：强劲、残暴、恐怖、逆天、变态（多用于消色差）、夸张、吓人、权威（"镜头的分辨率还是太权威了"）、性能霸权时刻、Tier 0 / Tier 0.5 梯队、数值怪、洒洒水的难度、白开水（指像差少、虚化中性）
**性能崩**：坠机、劣化、开裂（子午弧矢开裂/分裂）、塌（中场塌了一点）、跌落、露馅、露出马脚、放弃治疗、像差蹦我脸上
**差评** ★：史、依托、菜、牢（牢旧的单反设计）、不配上桌、太菜
**虚化**：白开水、中性、二（"直接就是二起来了"）、二线性、亮边、带核、柔和、柠檬、猫眼、圆神、旋、富士山（亮度递减的柔和光斑）
**动作**：肘击 / 肘赢 / 肘得有来有回、干色差 / 找茬色差、打靶、手搓 / 捏 / 搓（逆向优化）、拉皮（同构型缩放）、数毛、甩锅给对焦组、品鉴 / 不得不品鉴的一环
**工况**：地狱工况、拍菜环节、拍大头、全身人像、近摄、远摄
**称呼**：确善能（Cosina）、蛤能（Canon）★、马哥65（适马65mm F2）、索尼神力、索尼光学王朝、原田桑、尼小子/松小子 ★、键摄、路边UP主、cjb文（吹捧文）★
**网络梗**（点缀用）：轮椅（用起来很省事/无脑）、坠吼滴、水灵灵的、此时此刻恰如彼时彼刻、原田不语只是一味……、我超冰、一颗赛艇、XX是好文明（"低色差是好文明"）、重要的事情说三遍、横批

**专业术语保持英文或原样**：FFT MTF、MTF50、BFL、CRA、Layout、Rayfan、Tan Coma、Datasheet、Trade-off、budget、Working F-number、Cover Glass、Spot、ED、NBFD、VCM、STM、MFD。软件名：CODE V（他写作 Code Five / Code V 都可）、Zemax、MTF Mapper。

**单位与数值写法**：80线对每毫米、MTF50、30线对的反差0.9、色焦移宽度24微米、光学总长135毫米（也写 mm）、放大倍率0.02倍、物像共轭距5米、2ev的暗角、边缘照度0.25。

## 5. 修辞手法

- **数据 + 参照物**："只有索尼85GM2的五分之一还不到""是佳能RF 85mm F1.2 L的三分之一""大约是本时代普通镜头的两倍不止"。
- **反讽 / 夸张收尾**："全画幅500MP不是梦想。""6100万像素太少了。"
- **三连 + 横批**（自由档，整篇最多一次）："不要买福伦达！不要买福伦达！！不要买福伦达！！！……横批：Otus也是确善能。"
- **拟人化厂商/设计师**："原田不语，只是一味增大球差。""球差在捣鬼""公差捣鬼""来自公差的肘击"。
- **历史对照开场**：先回到几年前的自己或行业（"在2021年的我还是个马小子"），再引出本期。
- **彩蛋 / 前瞻**：结尾放专利里看到的未发布镜头，"以上，就是一些新品消息了，我们并不确定是否是量产消息，直到它们被发布。"

## 6. 密度控制

梗和黑话是调味，不是主菜。原稿的真实密度大约是：

- 自由档：每 3–4 段出现一个明显的梗或狠话；技术论证段可以一个都没有。
- 送测档：每 6–8 段一个，且以"坠机""白开水""地狱工况""肘击"这类技术黑话为主，不用 ★ 词。
- 数据密集段（结构、材料、MTF 数值）优先把信息讲清楚；梗放在段尾或者过渡段。
- 同一个梗整篇别用超过两次（"坠机""当然"这类高频词除外）。

## 7. 不要这样写

- 营销腔、空泛赞美：「带来惊艳的画质体验」「兼具性能与便携」「堪称旗舰」。他的赞美永远带数字或像差归因。
- AI 腔：「总的来说」「值得注意的是」（偶尔可以）「让我们一起来看看」「一方面……另一方面……」「不仅……更……」排比、每段结尾拔高。
- 用 lp/mm、μm 这种符号代替中文单位（图上可以有，正文念出来要顺）。
- 在没有数据的地方下精确结论。
- 堆砌梗到影响可读性；一句话里塞两个网络梗。
