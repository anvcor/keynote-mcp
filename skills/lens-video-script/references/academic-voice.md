# 学术论文式批判写作（默认文风，2026-11-12 起）

来源：《星曜35APO》开篇。作者先说口语短句的版本「更偏向于论文吧」（是希望更像论文，不是嫌它像论文），随后明确：「不要使用skill里面那个。改为纯学术论文的风格。」看过按论文写的两段之后说：「这两段写的可以，就是要这种论文的感觉，然后多一点批判性。」

所以默认文风 = **学术论文的文体 + 批判性的立场**。批判性的立场、论证骨架和禁止清单沿用 `critical-voice.md`；那里的「纽约时报评论」式语气、口语化的锋利句子不再作为默认。早期 UP 主口吻（`voice.md`）只在他明确要「老风格 / 玩梗」时用。

## 1. 文体

- 像一篇中文光学 / 工程类论文的正文：客观、第三人称、书面语，句子完整，逻辑连接词齐全（「其中」「此后」「由此可见」「然而」「需要指出的是」）。
- 主语是对象和事实，不是「我」「你」「大家」。需要提到本频道时写「本文」「本研究」「笔者」。
- 术语准确，并保持全文一致：复消色差（apochromatic）、卡口、焦段、像高、出瞳、主光线角、FFT MTF、纵向色差、色焦移。英文术语第一次出现时可以括注。
- 时间、型号、焦段、数值写全：「1998年的90mm F2」「APO-Summicron-M 35mm F2 ASPH.」「30线对每毫米」。
- 一段讲一件事，2–5 句。先陈述事实或数据，再给出由此得出的判断。

## 2. 批判性放在哪里

批判性是论证上的，不是语气上的。它体现为：

- **区分事实、厂商宣称和推断。** 厂商的定位、「APO」之类的命名、官方 MTF，都写成「厂商宣称」「官方给出」，再拿仿真或实测去检验：「该镜头以 APO 命名，然而其 0.06 倍下的色焦移宽度为【待填】，已超出常用的复消色差判据。」
- **指出比较的前提。** 两只镜头对比时，说清楚条件是否一致（光圈、物距、像高、测量方式），条件不一致就说明结论的适用范围。
- **说明数据的局限。** 仿真是几何光斑还是含衍射，还原结构是否经过官方验证，实测受像素尺寸限制，这些写进正文，用一句话交代。对本文自己的方法同样如此。
- **对流行说法和行业惯例给出检验。** 先原样陈述说法，再给出检验方法和结果，最后指出它为何不成立或在什么条件下成立。
- **结论有保留。** 没有测过的判断用「通常被视为」「从产品图看」「在现有数据范围内」限定；测过的就直接下结论，不必含糊。

## 3. 句子与用词

- 判断用陈述句直接写出，不加感叹和反问。
- 作者自己的概念照用（虚空贷款、颗粒度、超频像场、发烧级），放进书面句子里，必要时加引号：本质上是一笔「虚空贷款」。
- 数字带单位、带参照：「约为某镜头的五分之一」。参照物只能来自 benchmarks.md 或他给的数据。
- 不为了论文感堆砌术语和长定语；一句话里只放推进论证的信息。

## 4. 禁止

- 口语和网络用语：「拿性能说话」「够锐」「拔尖」「露馅」「一塌糊涂」之外的狠词（「一塌糊涂」是他的词，可以留在判断句里）。
- 第二人称和对观众喊话：「你会发现」「大家可以看到」。
- 修辞：排比、比喻、口号式对仗、反问、预告钩子（沿用 critical-voice.md 第 4 节）。
- 没有证据的绝对化断言：「第一次」「最常见」「唯一」，除非有出处。
- 学术腔的空话：「具有重要意义」「值得深入研究」「综上所述」（总结节可以用「综上」一次）。
- 编造数据（SKILL.md 数据铁律不变）。

## 5. 作者认可的段落（星曜35APO 图1、图2，原样）

> 徕卡APO-Summicron-M系列是M卡口镜头中以成像性能为首要设计目标的产品线。多数M卡口镜头侧重小型化与成像风格，而该系列以高分辨率和复消色差（apochromatic）校正为定位，通常被视为M卡口镜头中成像性能最高的一档。该系列始于1998年的90mm F2，此后依次推出75mm（2005年）、50mm（2012年）与35mm（2021年）三个焦段。

> 其中，2021年3月发布的APO-Summicron-M 35mm F2 ASPH.是该系列目前成像性能最强、体积最小的型号，属于M卡口镜头中最高端的发烧级产品。
